## Overview

This project implements an end-to-end text preprocessing workflow on movie overview data from The Movie Database (TMDB). The primary goal is to transform raw, noisy natural language text into standardized tokens ready for downstream Natural Language Processing tasks, such as text classification, sentiment analysis, topic modeling, or information retrieval.

The repository supports both interactive exploration via Jupyter Notebook and automated command-line execution via a standalone modular Python script.

## Dataset Specification

The dataset contains movie metadata scraped from The Movie Database (TMDB):

- Raw records: 100 entries with 10 features:
  - `ID`: TMDB movie identifier.
  - `Title`: Release title in English.
  - `Original Title`: Original title in the source language.
  - `Release Date`: Movie release date (YYYY-MM-DD).
  - `Popularity`: TMDB popularity metric score.
  - `Vote Average`: Average user rating score.
  - `Vote Count`: Total count of user ratings.
  - `Original Language`: ISO 639-1 language code.
  - `Adult`: Boolean flag indicating mature content.
  - `Overview`: Natural language summary and plot synopsis.
- Preprocessed records: 98 entries (2 rows with missing synopsis removed) with 16 features, adding:
  - `clean_overview`: Fully sanitized, lowercase, stopword-free synopsis.
  - `original_word_count`: Word count of the raw synopsis.
  - `clean_word_count`: Word count of the cleaned synopsis.
  - `stemmed_overview`: Token stems generated by the Porter Stemmer.
  - `lemmatized_overview`: Dictionary-validated lemmas generated by WordNet.
  - `pos_tags`: Universal Part-of-Speech tagged token tuples.

## Preprocessing Pipeline Stages

The transformation process comprises seven sequential stages:

### Stage 1: Data Ingestion and Missing Value Handling

Raw records are ingested from `data/tmdb_movies.csv`. Missing values in the text target field `Overview` are identified (2 records out of 100). These records are safely dropped, resulting in 98 complete samples for subsequent processing.

### Stage 2: Noise Removal and Normalization

Raw synopsis text contains extraneous formatting and non-semantic characters:

1. Lowercasing: Text is converted to uniform lowercase to prevent casing discrepancies.
2. HTML Tag Removal: BeautifulSoup parses and extracts raw text, stripping markup tags such as `<div>`, `<p>`, and `<a>`.
3. URL Filtering: Regular expressions remove web links starting with `http`, `https`, or `www`.
4. Punctuation Stripping: Standard ASCII punctuation marks (`string.punctuation`) are removed using character translation tables.
5. Emoji Removal: Comprehensive Unicode range pattern matching eliminates graphic emojis.
6. Emoticon Removal: Regex expressions match and strip classic keyboard emoticons (such as `:)`, `:-D`, and `:P`).

### Stage 3: Vocabulary Refinement and Normalization

1. Stopword Removal: Common grammatical stopwords (such as "the", "is", "at", and "which") are filtered using the NLTK English stopword corpus.
2. High-Frequency Word Pruning: Word frequencies across the entire corpus are tallied with `collections.Counter` and visualized in a frequency bar chart. The top 10 most common words across the dataset are removed to eliminate generic over-represented vocabulary.
3. Rare Word Pruning: Hapax legomena (words that appear exactly once across the entire corpus) are identified and purged to reduce feature space sparsity.
4. Chat-Word and Slang Expansion: Informal abbreviations (such as "u", "ur", "btw", "idk", "omg", "thx", "pls") are expanded to their formal grammatical equivalents.
5. Whitespace Stripping: Redundant consecutive spaces, tabs, and newline characters are collapsed into single spaces.

### Stage 4: Quantitative Reduction Analysis

The impact of noise reduction on token count is measured by comparing `original_word_count` against `clean_word_count`.

$$
\text{Reduction Percentage} = \frac{\text{Mean Original Word Count} - \text{Mean Clean Word Count}}{\text{Mean Original Word Count}} \times 100\%
$$

- Mean Original Word Count: 45.78 words
- Mean Cleaned Word Count: 14.00 words
- Average Noise Reduction: ~69.4% reduction in non-informative tokens

### Stage 5: Morphological Analysis (Stemming vs Lemmatization)

To standardize inflected word forms, two complementary morphological techniques are applied:

1. Porter Stemmer (Heuristic Slicing): Applies rule-based suffix truncation. Fast and effective for information retrieval, though it may produce non-dictionary stems (for example, "fighting" becomes "fight", "transformations" becomes "transform").
2. WordNet Lemmatizer (Vocabulary-Aware): Maps words to their authentic base dictionary forms (lemmas) utilizing the WordNet lexical database.

### Stage 6: Syntactic Processing (POS Tagging and Chunking)

1. Part-of-Speech (POS) Tagging: Each token is mapped to its syntactic role using the Universal POS Tagset:
   - `NOUN` (nouns)
   - `VERB` (verbs)
   - `ADJ` (adjectives)
   - `ADV` (adverbs)
   - `ADP` (adpositions and prepositions)
2. Chunking (Shallow Parsing): Phrases are grouped into syntactic structures using a regular expression grammar:
   - Noun Phrase (`NP`): `<DET>?<ADJ>*<NOUN>+`
   - Verb Phrase (`VP`): `<VERB><.*>*`
   - Prepositional Phrase (`PP`): `<ADP><NP>`
   - Adjective Phrase (`ADJP`): `<ADV>*<ADJ>+`

### Stage 7: Dataset Export

The transformed DataFrame containing original metadata and all engineered NLP features is persisted as `data/tmdb_preprocessed.csv`.

## Quickstart and Installation

### Prerequisites

- Python 3.10 or higher
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/welfeesukardi/Text-Scraping-and-Preprocessing.git
cd Text-Scraping-and-Preprocessing
```

### 2. Set Up a Virtual Environment

```bash
python -m venv venv

# Windows (PowerShell)
.\venv\Scripts\Activate.ps1

# Linux / macOS
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Download Required NLTK Corpora

The automated script handles this automatically on execution. If running manually in an interactive environment:

```python
import nltk

nltk.download("punkt")
nltk.download("punkt_tab")
nltk.download("stopwords")
nltk.download("wordnet")
nltk.download("omw-1.4")
nltk.download("averaged_perceptron_tagger")
nltk.download("averaged_perceptron_tagger_eng")
nltk.download("universal_tagset")
```

## Usage

### Method A: Execute the Command-Line Script

Run the complete pipeline from terminal:

```bash
python src/preprocess.py
```

Optional CLI parameters:

```bash
python src/preprocess.py --input data/tmdb_movies.csv --output data/tmdb_preprocessed.csv --top-frequent 10
```

### Method B: Interactive Jupyter Notebook

Launch Jupyter Notebook to inspect step-by-step code, intermediate tables, and word frequency charts:

```bash
jupyter notebook notebooks/Preprocessing_Rava_Welfee.ipynb
```
